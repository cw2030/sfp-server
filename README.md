### 项目说明
本项目是一个基于 Rust 的 SFTP 服务器，用于提供安全的文件传输服务。
项目采用 Rust 语言开发，支持多线程并发处理，提供文件上传、下载、删除、重命名等操作。
特性如下：
- 提供文件上传、下载、删除、重命名等操作。
- 支持文件权限管理，包括读、写权限。
- 支持上传、下载限速设置
- 完整审计日志记录，包括连接、操作、错误等。
- 简单用户管理前端，包括用户添加、删除、修改密码等。

### 项目架构
- 前端：基于 Vue 3 + TypeScript + Element Plus 开发，提供用户管理、文件上传下载等功能。
- 后端：基于 Rust + Actix-web 开发，提供 SFTP 协议实现。
- 数据库：基于 mysql 开发，存储用户信息、文件元数据等。

### 项目运行环境
#### rust 环境
- rust版本：1.65+
- actix-web版本：4.0+

#### vue 环境
- vue版本：3.0+
- node版本：24.0+

### 项目编译与运行
#### 前端 编译与运行
```bash
cd frontend
npm install
npm run build
```
#### 后端 编译与运行
```bash
cargo run --release
```
